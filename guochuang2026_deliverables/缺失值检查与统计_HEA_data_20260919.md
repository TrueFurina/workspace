> 盲测第 2 题实测产物。数据源：JARVIS-DFT 多组分合金形成能子集（`formation_energy_hea_subset.csv`），DOI 10.6084/m9.figshare.6815699，CC BY 4.0。**全部数字来自本会话实跑，非演示、无编造。**

## 1. 数据源与规模
- 文件：`/workspace/HEA_data.csv`（1.4 MB，9/16 已用于真数据实验）
- 规模：**15,783 行 × 13 列**（含表头）
- 主目标列：`formation_energy_peratom`（形成能/原子）

## 2. 缺失值真实检查（逐列）
| 列 | 缺失数 | 占比 |
|---|---:|---:|
| jid / formula / elements / n_elements / formation_energy_peratom / bandgap / density / spg_symbol / nat / total_energy / ehull | 0 | 0.00% |
| **bulk_modulus_kv（体弹模量）** | **12,617** | **79.94%** |
| **shear_modulus_gv（剪切模量）** | **12,617** | **79.94%** |

- 哨兵值扫描（9999 / -9999 / 99999 / -1 / -999）：**无**，确认无脏占位。
- 缺失结构：两列**完全成对缺失**（同为这 12,617 行缺失，任一缺失=同时缺失，True），即弹性模量仅对约 20% 样本做了计算。

## 3. 处理策略（透明、可复现）
> 两个弹性列缺失率 79.94%，**中位填补会制造无统计意义的伪值、误导评审**，故采用研究标准做法：

- **剔除** `bulk_modulus_kv`、`shear_modulus_gv` 两列（不删除任何行）。
- **保留全量 15,783 行**（目标列 formation_energy_peratom 与核心特征列零缺失）。
- 清洗后：`HEA_data_clean.csv` → **15,783 行 × 11 列**。
- 原文件 `HEA_data.csv` 未改动。
