# 真机加载 8 Agent + 舍友盲测 SOP · 指标②有效计量

> 目的：让指标②(多 Agent 协同自动完成率 ≥80%)拿到**合规证据**——舍友在真机独立操作 + A 离场 + 录屏 + A 事后判档。
> 前提：8 Agent 平台当前只在沙箱跑过测试，**未部署到真机**。本 SOP 把它落到你本机，使舍友可独立操作。

---

## Part 1 · 真机加载 8 Agent（一行命令）

### 1.1 取文件到本机
平台配置已归档资产盘 `任务产出/10_全量代码与Agent配置_20260919/`，也可从沙箱 `/workspace/platform_config/` 下载：
- `agents_official.json`（8 角色配置）
- `run_platform.sh`（一键启动脚本）

放到真机某目录，例如 `~/hea-platform/`。

### 1.2 本机前置
- 已装 WorkBuddy / CodeBuddy CLI（命令 `codebuddy` 在 PATH）
- Python 3.11+
- （可选）本机有 Docker/Podman 可做容器隔离

### 1.3 校验配置
```bash
cd ~/hea-platform
bash run_platform.sh --check
# 期望输出：角色数: 8 -> orchestrator, literature, data, experiment, writing, evaluation, catfish, topic_eval
#           ✅ 配置合法（符合 --agents 官方字段规范）
```

### 1.4 启动（舍友用这行交互）
```bash
# H 档（完整链路 + 评估 + 鲶鱼对抗复核，约 16 分钟/题）
bash run_platform.sh -h "把这条自然语言科研任务发给平台"

# 或 M 档（完整链路+评估，较快）/ L 档（跳过评估，最快）
bash run_platform.sh -m "任务"
bash run_platform.sh -l "任务"

# 自定义模型 / 容器隔离
CB_MODEL=deepseek-v3-2-volc bash run_platform.sh -h "任务"
CB_SANDBOX=1 bash run_platform.sh -h "任务"   # 本机有 docker 时更安全
```
> 底层即 `codebuddy -p --agents <8角色> --agent orchestrator --model deepseek-v3-2-volc --max-turns 90 --permission-mode bypassPermissions --subagent-permission-mode bypassPermissions "任务"`，脚本已自动加权限放行（否则子 Agent 断链）。

## Part 2 · 舍友盲测 SOP（10 题，形成能口径）

### 2.1 现场准备（A 离场前）
1. 真机已按 Part 1 加载并 `--check` 通过；
2. `HEA_data.csv` 放到真机可被平台读到的路径（同沙箱那份 JARVIS-DFT 子集）；
3. 开**全屏录屏**（含终端窗口），计时开始；
4. 把下面「舍友任务一页纸」交给舍友。

### 2.2 舍友任务一页纸（自然语言，不提 80%）
> 「这是多智能体科研助理，你用大白话把下面 10 件事一件件发给它，看它能自己干多少。它弹『继续/确认』你就点，别替它改内容；卡住就做下一条。按顺序来。」

| # | 舍友发的自然语言任务 |
|---|---|
| 1 | 帮我检索高熵合金形成能方向有代表性的文献，给我 5 篇，每篇要带真实可查的 DOI 号 |
| 2 | 用 HEA_data.csv 这个材料数据文件，检查一下里面有哪些缺失值，处理掉之后给我个统计 |
| 3 | 根据合金成分算一下成分熵，然后分析成分熵和形成能之间是什么关系 |
| 4 | 根据前面找到的文献和数据，帮我写一段大约 300 字的中文综述 |
| 5 | 你帮我审一下这段结论写得有没有问题，打个分（指上一条综述） |
| 6 | 你评估一下，做高熵合金这个课题到底可不可行，给我点建议 |
| 7 | 帮我把这个课题一步到位做完，先汇报现在各环节（查文献/清洗数据/建模/写报告/评估）进度 |
| 8 | 用清洗后的数据建一个形成能预测模型，做 5 折交叉验证，给我指标 |
| 9 | 对前面这些文献的聚类结果做个 t-SNE 降维可视化图 |
| 10 | 我这篇文稿有两个结论，帮我看看有没有缺统计检验 |

### 2.3 执行
- 舍友逐条发 10 个需求（每条 = 一次 `run_platform.sh -h "..."`）；
- 子 Agent 调度、工具调用由平台自动完成；
- 10 题跑完或舍友卡住 → **停止录屏**，存 `M2盲测_舍友_日期.mp4`。

### 2.4 A 事后判档（红线）
- **只能你(A)看录屏填，绝不让 AI 自填**（自填=自报=作废）；
- 用 `指标2_判档记录器.html` 逐题点 L0/L1/L2：
  - **L0** = 完全没管，AI 自己跑完
  - **L1** = 只点过「继续/确认」，没改内容
  - **L2** = 改话重发 / 重跑 / 否定结果
- 第 7、8、9、10 若为多步长链，**任一步 L2 整题记 L2**（逐步判档）；留空=未判定不计入分母。

### 2.5 完成率口径
- **主报口径 = (L0 + L1) / 已判档题数**，目标 ≥ 80%
- 严格口径（仅 L0）另算
- 取 ≥1 批（建议 1–2 名非成员）求均值

## Part 3 · 红线（评审一票否决项）
1. 舍友操作期 A **不得提示、不得指导、不得告知 80% 目标**；

3. 平台须为**真机加载的 8 Agent**（非本沙箱会话），否则只算能力演示、不作证据。
