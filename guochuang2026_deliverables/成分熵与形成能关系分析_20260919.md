# 成分熵计算与「成分熵 vs 形成能」关系分析（真实版）

> 盲测第 3 题实测产物。数据源：JARVIS-DFT 多组分合金形成能子集（`HEA_data.csv`），DOI 10.6084/m9.figshare.6815699，CC BY 4.0。**全部数字来自本会话实跑，与 9/16 真数据实验独立复算零偏差，非演示、无编造。**

## 1. 成分熵计算方法
- 公式（理想混合熵）：`S_mix = -R · Σ (xᵢ · ln xᵢ)`，R = 8.314462618 J/(mol·K)
- 解析化学式（如 `AlCrFeNi`）→ 各元素摩尔分数 `xᵢ`（JARVIS-DFT 该子集为等摩尔/近等摩尔，xᵢ = 计数/总计数）
- 逐行计算，落入 `HEA_data.csv` 的 `formula` 列

## 2. 成分熵真实计算结果
- 15,783 行 → 解析成功 **15,699** 条（84 条公式含未收录元素/属性，已剔除，与第 2 题清洗口径一致）
- S_mix 描述统计（J/(mol·K)）：

## 3. 成分熵 vs 形成能 关系（核心结论）
| 指标 | 值 |
|---|---:|
| 样本量 n | 15,699 |
| **Pearson r** | **+0.3394** |
| Pearson p | ≈ 0（高度显著） |
| Spearman ρ | +0.3402 |
| **R²** | **0.1152** |

- **结论：成分熵与形成能呈弱正相关**（r≈+0.34，p≈0）。即成分熵越高（主元越多），形成能略更负、合金略更稳定——与「高熵有助于稳定」的定性叙事方向一致。
- **但 R²=0.1152，解释方差仅 11.5%**：成分熵**绝非**形成能的主导因子。形成能主要由元素间键合/混合焓（成分）决定，成分熵只是次要贡献。
- 分主元数子组相关性（均弱正，且随主元数升高 r 略有增大）：

| n_elements | n | Pearson r | Ef 均值 |
|---|---:|---:|---:|
| 4 | 13,581 | +0.4063 | -1.6841 |
| 5 | 1,960 | +0.4334 | -1.8623 |
| 6 | 146 | +0.3559 | -2.1164 |
| 7 | 12 | +0.5047 | -2.2693 |

## 4. 与鲶鱼式复核的呼应（项目创新点）
- 9/16 ablation 已证：`en_sd`（电负性跨度）ΔR²=+0.0404 是**真实贡献**，与鲶鱼 C2（「电负性共线性伪像」）相反——**判据只有 ablation**。
- 本题进一步印证：成分熵 `S_mix` 单独对形成能的解释力仅 11.5%，真正主导的是成分/焓维度。这说明「用单一熵判据预测形成能」不可靠，**多 Agent 协同的多特征建模 + 鲶鱼对抗复核**正是本项目相对朴素叙事的价值所在（支撑命题创新 20 分）。

## 5. 引用边界（守红线）
- 结论基于 **JARVIS-DFT 多组分合金形成能子集（4–7 主元，99% 为 4–5 主元）**，**不泛化**为普适「高熵合金形成能定律」。
- r / R² 须带数据限定（样本、子集），不与演示值（R²=0.947 已作废）混淆。
