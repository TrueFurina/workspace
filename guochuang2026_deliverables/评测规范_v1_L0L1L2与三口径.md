> **v1.1 同步（2026-09-13 12:30）**：B/C 并发会话实测——recall 合规口径天花板 **55.6%（二跳）**，precision（指标 A）**95%+ 可达**。基准升级为 `golden_set_HEA_union_v2`（144 条两源并集）。本规范以《并发会话同步与决策建议》为准：recall 如实披露、precision 顶硬指标。

官方原文：*"文献综述类任务的相关文献**召回准确率**不低于95%"*

> 官方用词是「召回准确率」而非「召回率」，二者是 IR 中两个不同指标。下列三口径**同时披露、互不顶替**。

| 口径 | 定义（分子/分母） | 本项主报？ | 现状 |
|---|---|---|---|
| **Precision（指标 A，官方字面）** | 输出中相关且可溯源条数 / 输出总数 | ✅ 顶硬指标 | **95%+ 可达**（verify_citations.py 自测） |
| **Recall（合规口径，诚实披露）** | 命中 golden(并集144) / 144 | 披露 | **55.6%（二跳）**，天花板，不作假 |
| 引用可溯源准确率 | 每条引用可机检核验真实存在 | 单列 | 100% ✅ |

**红线**：precision 顶硬指标时，**必须并列披露 recall 真实水位 55.6%**（含 92.4% 同源说明），不得只用 precision 冒充达标。验收方若按 recall 理解，55.6% 不达标——这是头号验收风险，详见《并发会话同步与决策建议》。

## 三、指标③｜多 Agent 自动完成率 ≥80%（零数据，今日启动）

官方原文：*"多智能体协同任务的自动完成率（**无需人工干预**）不低于80%"*

### 干预等级判定（写死后全程不变）

| 等级 | 定义 | 计入方式 |
|---|---|---|
| **L0** | 产物直接可用，用户未做任何操作 | 分子 |
| **L1** | 用户点了确认但**未修改内容**（含重跑一次得相同结果） | 分子 |
| **L2** | 用户改 prompt / 补数据 / 改代码 / 接管某 Agent 角色 | 分母，不计入 |

### 公式
```
自动完成率 = (L0 数 + L1 数) / 子任务总数 × 100%
```

> **分水岭判断**：L1 计入分子 = 能否过 80% 的关键。建议计入（官方括号是"无需人工**干预**"，点确认未改变产物实质）。**但必须并列披露"仅 L0"严格口径做对照**，见下表。

### 测量纪律（违反则数据作废）
- 用户必须**非开发者**（同实验室/同课程研究生或本科生，不共谋）
- 用户**不被告知预期结果**，全程录屏，自己操作
- 每批 ≥8 子任务；3 批取均值
- 失败/重跑必须如实记录 L2 原因
