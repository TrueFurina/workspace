## 1. 【P0】≥80% 自动完成率：今天必须跑第一次

三大硬指标里只有这一项是**零数字、零复算脚本**。它有官方括号定义：

> 多智能体协同任务的自动完成率（**无需人工干预**）不低于80%

今日行动 §硬伤 3 自己点破了：9/11 那次"5 类全 success、全 L0"是**无人值守**跑的，用户根本没机会干预——**这个 100% 不成立，报出去一句话打穿**。

### 为什么今天（9/13）就要启动，不能等到 9/18
节奏表写 9/18 前累计 3 次取平均。倒推：需 3 次有效测量 + 每次需**真实用户**（非开发者自评）+ 录屏。今天不约人、不跑第一次，9/18 拿不出 3 次可信数据。这一项一旦零分，①② 再好也是"硬指标未达标"。

### 今天照单执行（编号步骤）

**步骤 1｜写死"干预"判定口径（先于任何测量，2 小时内）**

| 等级 | 定义 | 计入 |
|---|---|---|
| L0 | 产物直接可用，用户未做任何操作 | 分子 |
| L1 | 用户点了确认但**未修改内容**（含重跑一次得相同结果） | 分子 |
| L2 | 用户改 prompt / 补数据 / 改代码 / 接管某 Agent 角色 | 分母，不计入 |

> 自动完成率 = (L0+L1) / 子任务总数。
> **L1 是否计入分子 = 过不过 80% 的分水岭。** 建议计入（官方括号是"无需人工**干预**"，点确认未改变产物实质），但**必须并列披露"仅 L0"严格口径**做对照。

**步骤 2｜今天约 2 名真实用户**：同实验室/同课程的研究生或本科生，与你不共谋；不告知预期结果、全程录屏、用户自己操作。（开发者自评在答辩必被质疑——对应评分点"实质性贡献"。）

**步骤 3｜用课题 X（HEA）跑第一次闭环，拆 8–10 子任务**，按 `subtask_id, agent, action(L0/L1/L2), 备注` 记 CSV —— 这就是答辩能掏出的证据。

## 2. 【P1】A2 从 90.2% 到 95%：路径清楚，今天解锁前置

### 结论：走得通，不要降级口径
R6 用纯检索工程把合规口径从 69.2% 推到 **90.2%（120/133）**（+21pp，零开卷），差 7 条。你自己的报告已给出短板：

> 年份分片用了 2019/2021/2023/2025，**漏掉 2024**——而 golden set 中 2024 文献占比过半。

这是明确 bug，不是天花板。R8 崩是 OpenAlex 配额耗尽（同 IP 50 分钟约 2000 次请求），非方法论问题。你把 R8 失败转成三条架构结论（多源互备、失败率熔断、断点续跑）——**这个处理极对，失败变工程资产，本身就是答辩素材。**

### 今天一件低成本高价值的事：补测 Precision 口径
官方写的是「相关文献**召回准确率**」，不是"召回率"，二者是 IR 里两个不同指标：

| 口径 | 定义 | 你的现状 |
|---|---|---|
| Recall（你测的，严格，主报） | 命中 golden / 全集 133 | **90.2%**（冲 ≥95%） |
| **Precision（官方字面）** | 输出中真相关的比例 | 未测，大概率 ≥95% |
| 引用可溯源准确率 | 每条引用可机检核验 | 100% ✅ |

补测成本：抽 R6 综述引用列表（40–60 条）人工判相关，1–2 小时。**红线：Precision 只能并列披露，绝不可顶替 Recall 冒充达标。** 只有 Recall 真推到 95%+ 才无懈可击。

### 配额恢复后补捞顺序（带断点续跑，防 R8 雪崩）
1. 补 **2024 年份分片** → 捞回 #2 Graph representation、#9 ML potential（明确 bug 产物）
2. 补**中子主题**（中熵/纳米晶/增材/辐照）→ #53 #56 #65
3. 补**材料基因组 / 迁移学习**主题词 → #25 #35

捞回 7 条即 95.5%（127/133）。**前置（今天就能办，免费）**：Semantic Scholar API Key + OpenAlex `mailto` 礼貌池。脚本必须分阶段落盘 + 断点续跑；单源失败率 >30% 切备份（Crossref 未被限流，可作主力备份）。
