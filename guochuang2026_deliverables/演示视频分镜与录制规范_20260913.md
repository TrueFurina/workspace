# 演示视频分镜与录制规范

> 官方交付物硬要求：*"可演示的原型系统/Demo（**需提供演示视频，清晰展示多智能体协同全过程**）"*
> 评分暗门（来自评审视角报告）：评委要看的不是"一个 Agent 答题"，而是 **多个 Agent 接力 + 中间结果 schema 化流转**。
> 指标③（≥4 类 Agent）与指标②（自动完成率）**共用这一次闭环录制**——省时且证据互证。

---

## 一、必须展示的"评分暗门"清单（缺一项扣分）

1. ✅ **自然语言一句话下达**科研任务（命题核心："一句话调度"）
2. ✅ **中枢做任务拆解**（Plan，展示子任务树）
3. ✅ **≥4 类 Agent 逐一出场接力**：文献 → 数据 → 代码实验 → 论文写作 → 成果评估
4. ✅ **中间结果流转可视化**（Agent 间传参，不是人肉复制）
5. ✅ **知识库沉淀**（最后一步自动入库，对应核心功能③）
6. ✅ **合规/查重辅助**（成果评估 Agent 出场，对应核心功能④）
7. ✅ **尽量无干预**：展示 L0/L1 标注（对应自动完成率指标②）

## 三、录制规范（防被质疑"演"）

- **无剪辑**：单条录屏或标注"仅剪接转场"，保留时间戳
- **真实闭环**：用 M1 同一课题 X，录屏与 CSV 可交叉验证
- **标注干预**：每出现一次 L0/L1/L2，画面角标实时标（用评测规范 v1 定义）
- **可复现**：附带 `.json` 任务日志 + 统计脚本输出，答辩可当场重跑
- **主权/货币/颜色**：地图合规、涨红跌绿、¥
