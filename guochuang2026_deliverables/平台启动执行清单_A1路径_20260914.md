## 3. 我已生成的配置文件（省掉你 5.2 的一半工作量）

清单只给了 `agents.json` 草案、**7 个 Schema 只写了文件名没写内容**。我已按 §3 各 Agent 的 `required_fields` 补全：

| 文件 | 内容 |
|---|---|
| `config/agents.json` | 7 角色 + orchestrator 完整配置（`{{...}}` 待按 6.2 校准） |
| `config/schemas/schema_literature.json` | `queries[]`、`citations[].doi` |
| `config/schemas/schema_data.json` | `missing_handling`、`profile.row_count` |
| `config/schemas/schema_experiment.json` | `executed`、`raw_output_ref`、`not_obtained[]` |
| `config/schemas/schema_writing.json` | `citations[].{claim,source_id}`、`insufficient_evidence[]`、`rewrite_tool_used` |
| `config/schemas/schema_evaluation.json` | `metrics_verified[].{claimed,recomputed,match}` |
| `config/schemas/schema_catfish.json` | `metrics_verified[]`、`self_reviewed_previous` |
| `config/schemas/schema_topic_eval.json` | `dimension_scores.{coverage,data_avail,novelty,feasibility}`、`recommendation` |

> Schema 里的防编造字段是**答辩加分点**：`missing_handling`（禁静默填充）、`not_obtained[]`（跑不出据实列）、`rewrite_tool_used`（恒 false，不得用改写工具规避查重）、`self_reviewed_previous`（鲶鱼必须审自己）。
