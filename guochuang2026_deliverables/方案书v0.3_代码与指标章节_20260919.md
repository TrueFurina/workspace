- 形态:WorkBuddy / CodeBuddy 原生 `--agents` 编排,主 Agent `orchestrator` 自主 Triage + 分派。
- 一键启动:`run_platform.sh`(只传参,不做调度/校验逻辑,守住 R5)。
- 8 角色(超额满足 ≥4 类):`literature` / `data` / `experiment` / `writing` / `evaluation` / `topic_eval` / `catfish` / `orchestrator`,配置经 `--check` 校验合法(官方字段规范)。
- 防编造机制:链路熔断(`synthetic_data_used` 判定)、`not_obtained[]` 显式声明、同源自测 loop 作废。
