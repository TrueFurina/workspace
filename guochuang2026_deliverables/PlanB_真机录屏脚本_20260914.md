# Plan B 真机录屏脚本（A 类发布不通时的兜底）

> 触发条件：6.3/6.4 验证 = 「仅项目成员可见 / 链接打不开」→ 走本方案。
> 核心逻辑：真人**独立操作** + **录屏** + **盲测** + **你事后判档不介入**，与线上发布等效，合规。

---

## 一、预约与准备（你做，约 10 分钟）

1. 约 **3–5 名非团队成员**同学，线下到你电脑前（不同人不可重复算多次）。
2. 真机打开 WorkBuddy + 平台（8 角色 `agents_official.json` 已就绪 / `.codebuddy/agents/*.md` 已部署）。
3. 打开系统录屏并框选整个 WorkBuddy 窗口：
   - Win：`Win+G` 游戏栏 或 OBS；
   - Mac：QuickTime「新建屏幕录制」或 `Shift+Cmd+5`。
4. 把《用户一页纸》（见《M1启动包》）发同学**手机**，不念、不解释目标。

## 二、离场（最关键，5 秒）

5. 同学坐下，你**起身离开屏幕视线**（去旁边，不回头、不语音提示）。
6. 只说一句：「按手机上那页自己玩，卡住就跳过，不用管结果对不对。」然后走开。

## 三、同学独立操作（录屏中，不暂停）

7. 同学按一页纸完成 **10 题**（含 2 条 5 步长链；长链由 agent 内部自动接力，人只发一次指令）。
8. 全程录屏不暂停；同学遇到 agent 卡死可自行重试或跳过，你不在场不救。

## 四、收尾（你回来）

9. 同学做完你回来，**停止录屏**，文件命名：`PlanB_受试者X_YYYYMMDD.mp4`。
10. **你事后看录屏**，按 L0/L1/L2 填《PlanB_记录表模板.csv》——**不现场帮同学填、不替同学决定**。

## 五、纪律红线（与 M1 一致）

- 🚫 招募 / 现场**绝不说 80% / 指标 / 目标**（盲测）。
- 🚫 L0/L1/L2 由**你（人）看录屏判**，agent 不得自填（否则又成自报 100%，一票否决风险）。
- ✅ 录屏原片 + 填好的记录表 = 指标② 证据链，归档 Project Drive「任务产出」。
- ✅ 方案书如实写：「外部发布受平台权限限制，采用受试者到真机独立操作 + 录屏盲测。」

## 六、判档口径（复习）

- **L0** 无干预：发完指令全程不用管，agent 自己跑完。
- **L1** 仅点确认：中途只点了一次「继续/确认」，没改内容。
- **L2** 改过/重跑/驳回：编辑了指令、重跑、或否定了结果。
- **自动完成率 = (L0 + L1) / 总题数**；单步题零容忍（错 1 题即 <100%）；长链 5 步需每步自动（连乘，单步 ≥96% 才整链过）。
